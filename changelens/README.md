# ScopeProof ChangeLens

**Every small change, seen in context.** An AI-assisted scope-change review workbench for freelancers and small agencies, prepared for the HackerSquad AI Remote Hackathon in November 2026.

## Try it without an account, API key or payment

Download this folder and open **`dist/index.html`** in a modern browser. The file contains the model and application; it makes no inference requests and needs no build step. In the ScopeProof GitHub repository, this folder is named **`changelens/`**. Download the branch ZIP, extract it, then open `changelens/dist/index.html`. Do not open the HTML through GitHub's code viewer and expect it to run there.

Alternatively, serve this folder with `python3 -m http.server 8080` and open `http://localhost:8080/dist/`. Clipboard permissions and SHA-256 availability depend on browser context; the UI reports unavailable features. A hosted owner-only preview is for the author and is **not judge access**. Judges should use the standalone file or run instructions.

1. Press **Compare requests** on the synthetic example.
2. Inspect the request for twelve posts beside original clause B2, which says eight.
3. Inspect the checkout exclusion and the finite revision limit.
4. Choose a decision and write a reason for all four requests. Enter a reviewer label.
5. Press **Prepare reviewed reply**. Copy the draft or export the evidence JSON.
6. Change a decision or source input: the previous draft/export becomes unavailable so a stale decision cannot be exported as current.

Nothing is sent to a client. No money is collected. The reviewer label is not authenticated.

## Why this exists

Small changes arrive in client messages while the original scope lives elsewhere. A freelancer needs to find the original wording, distinguish added deliverables from ambiguity, and explain their decision. ChangeLens brings those steps into one review surface with inspectable evidence and an exportable record. This is a proposed workflow improvement, not a measured claim about time savings or reduced disputes.

## Meaningful AI, with clear boundaries

- A trained TF-IDF + multinomial logistic-regression classifier suggests one of five service categories and exposes influential recognized words. Its weights are actually evaluated in the browser; it is not a mocked response or an API placeholder.
- The classifier is reused unchanged from ScopeProof v1. It was trained on 80 AI-assisted synthetic English examples. Scores are not calibrated probabilities of correctness.
- Retrieval uses the greater of TF-IDF cosine similarity and normalized word-overlap Jaccard similarity to rank up to three original clauses. This is lexical retrieval, not semantic entailment or contract interpretation.
- Separate explicit rules surface finite quantity differences, exclusions, unbounded requests, urgent timing and instruction-like text. These rules are not described as learned AI.
- No suggestion automatically decides that work is included. Every request requires a human classification and written reason before exporting.
- The reply is a deterministic template from the reviewer's decisions. It is **not** generated by an LLM.

## Implementation

`src/core.mjs` contains pure inference, matching, parsing, review and reply functions. `src/ui.js` owns browser state and safe rendering. `src/template.html` owns the interface. `src/model.json` contains the trained model. `build.mjs` creates a standalone `dist/index.html` from these files.

Development: Node.js 20 or newer. No npm dependencies to install.

```sh
npm test
npm run build
```

The optional original classifier retraining files are in `src/model-source/` and require Python, NumPy and scikit-learn. Their output is not automatically copied to `src/model.json`; review and evaluate a changed model before replacing the runtime model.

## Limitations

English only; small synthetic training set; lexical overlap can miss paraphrases or retrieve irrelevant clauses. Quantities are limited to explicit supported count words and units. Ranges, additive requests, mixed-language inputs, implied totals, multiple services in one clause, dates and conditional exclusions can require manual interpretation. Read the entire original scope. A match score does not establish inclusion. No legal advice, contract signing, client authentication, billing, PayPal integration or server persistence is implemented in **this ChangeLens module**. The older parent ScopeProof project has a separate sandbox integration; this demo does not claim that integration is tested.

Briefs remain in browser memory and are cleared on refresh. The export contains entered text. A host can retain ordinary access logs; browser-local analysis is not a promise that the hosting service has no logs. Source and model load with the app, but inputs are not transmitted to an inference API.
